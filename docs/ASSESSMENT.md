# Sanad Claw — تقييم شامل (2026-11-13)

> تقييم صريح لجاهزية التطبيق بعد جولة العمل الكاملة: إصلاحات الجهاز، الإصدار الموقّع، واجهة Chat/Agent، المرفقات، الألوان، واللغة.

## 2) ما أُنجز اليوم

### الإصلاحات الوظيفية
- `send_message` يعمل كاملًا على WhatsApp Business (7 أخطاء: حل اسم "WA Business"، جاهزية قائمة المحادثات، الانتظار قبل الرجوع، تجاهل معاينات "From ..."، التحقق من شريط العنوان فقط، اختيار حقل الرسالة الصحيح، وحاجز إلغاء عند فتح محادثة خاطئة).
- إصلاح حالة Accessibility التي كانت تعلّق على "Connecting/Disconnected" بعد إعادة التفعيل.
- فاحص التحديث: مقارنة نسخ صحيحة مع `-dev/-rc`، وقناة **Stable/Beta** يختارها المستخدم.
- اللغة الافتراضية الإنجليزية + إعادة الضبط للإنجليزية عند كل تحديث.

### الواجهة
- أزرار سريعة في الشريط العلوي: **الوضع الليلي/النهاري** و**EN/ع**.
- قسمان واضحان: **Chat** و**Agent** لكل الموديلات (سحابي ومحلي)، بألوان نشاط واضحة.
- **Enter يرسل** (بدل زر السهم الذي أُزيل)، مع بقاء الميكروفون وزر المرفقات.
- **رفع الصور والملفات** عبر منتقي النظام، مع شريحة مرفق قابلة للحذف؛ الملفات النصية تُدمج، والصور تُشار إليها بالمسار.
- وضع Agent يستخدم خلفية متوافقة مع الوضع النهاري (بدل الشريط الداكن الثابت).
- صفحة الموديلات تستخدم لون الثيم (برتقالي Ember) بدل البنفسجي العام.

### الإصدار
- مفتاح توقيع جديد + `assembleRelease` موقّع ومُتحقق.
- إصلاح CI: JDK 21 + `setup-android@v4` + حزم SDK (كان كل إصدار يفشل عند SDK).
- إصدارات منشورة على GitHub (dev-4 → dev-8).

### الاختبارات
- 318 اختبارًا / 57 صنفًا / 0 فشل (منها 6 اختبارات لمقارنة نسخ التحديث).

## 3) ما ينقص — خطة الغد (مرتبة)

### P0 (أمان وتوزيع)
1. تنفيذ QA الأمان اليدوي على الجهاز: **IJ1–IJ6** (حقن الشاشة)، **SD1–SD5** (OTP/بطاقات/IBAN)، **QV1–QV9** (أوامر صوتية)، **QP3–QP8** (تأكيدات مع إرسال حقيقي).
2. إضافة أسرار التوقيع الأربعة إلى GitHub Actions ليعمل النشر التلقائي (القيم جاهزة في `keys/GITHUB_SECRETS.txt`).
3. تدوير مفتاح OpenRouter المسرّب.
4. تثبيت APK الموقّع على جهاز نظيف واختبار الترقية.

### P1 (منتج)
5. **Wake word + STT مضمّن + TTS عربي** (أكبر فجوة منتج).
6. فصل سياق Chat عن Agent (منع النموذج من ادّعاء تنفيذ إرسال من تاريخ مهام سابق).
7. تنفيذ الروتين فعليًا عبر بوابة الأمان (حاليًا تذكير فقط).
8. Model routing/fallback + سقف تكلفة لكل مهمة.
9. صور متعددة الوسائط (base64) لموديلات الرؤية بدل المسار النصي.
10. إكمال ja/zh وإزالة آخر النصوص المضمّنة.

### P2 (جودة)
11. تفكيك God classes (`ChatScreen`, `DefaultAgentService`, `AutoReplyManager`).
12. بقايا أمان: cleartext عام، تحقق هوية `ExternalAutomationReceiver`، `AppLogStore`، `security-crypto` المهجور.
13. أتمتة CI/الإصدار بالكامل.

## 4) المنافسون والموقع الحالي

| المنافس | الفئة | أين يتفوق | أين يتفوق Sanad |
|---|---|---|---|
| **PokeClaw** (الأصل) | harness مفتوح | المجتمع والـ harness الأساسي | العربية، الأمان، التجربة، الإصدار الموقّع، المرفقات |
| **OpenClaw** | مساعد على سيرفر | النظام البيئي، القنوات، أتمتة المتصفح | تحكم فعلي بالهاتف، خصوصية على الجهاز، العربية |
| **AutoGLM / DroidRun / AppAgent** | وكلاء هاتف | بحثي/تجريبي، تكاملات | تطبيق جاهز، بوابة أمان، عربي، إصدار |
| **Tasker / MacroDroid / Automate** | أتمتة قاعدة | حتمية وسرعة | لغة طبيعية، مرونة، فهم السياق |
| **Gemini / ChatGPT / Apple Intelligence** | مساعدون | نماذج أقوى، تكامل نظامي | تحكم بالواجهة الأصلية، عربي، مفتوح المصدر، لا سيرفر |
| **Appium** | أتمتة اختبار | دقة للمطورين | موجّه للمستخدم النهائي، لغة طبيعية |

**الموقع الحالي:** Sanad Claw هو أحد القلائل الذين يجمعون: **عربي أولًا + تحكم كامل بالهاتف + بوابة أمان + مفتوح المصدر + إصدار موقّع**. لا يوجد منافس مباشر يجمع هذه الأربعة معًا اليوم.

## 5) المخاطر المفتوحة
- بنود الأمان اليدوية غير منفّذة → لا يُنصح بإصدار **stable** قبلها.
- أسرار CI غير مضبوطة → النشر التلقائي معطّل (النشر اليدوي يعمل).
- مفتاح OpenRouter لم يُدوّر بعد.
- Wake word/TTS غير موجودين → التطبيق ليس "hands-free" كاملًا.
- سياق Chat/Agent مشترك → قد يهلوس النموذج بإجراءات لم تُنفّذ.

## 6) الخلاصة
التطبيق انتقل من **~65%** إلى **~80%** جاهزية، مع إصدار موقّع يعمل، وإصلاح الميزة الأساسية (إرسال الرسائل)، وواجهة Chat/Agent احترافية. الخطوة الحرجة الوحيدة المتبقية قبل الإصدار المستقر هي **تنفيذ QA الأمان اليدوي**.
