# دليل المستخدم — Sanad-Agent (1.0.0)

دليل عملي لاستخدام التطبيق خطوة بخطوة. التطبيق واجهته عربية افتراضيًا (يمين-يسار)، ويمكن التبديل للإنجليزية من إعدادات اللغة.

---

## 1) التثبيت

1. ثبّت ملف APK:
   ```bash
   adb install -r PokeClaw_v1.0.0_<timestamp>.apk
   ```
   إن رفض أندرويد الترقية (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`) أزل النسخة القديمة واحتفظ بنسخة احتياطية للمحادثات أولًا.
2. افتح التطبيق واسمح بالإشعارات (لتظهر حالة المهمة وزر الإيقاف).

## 2) الأذونات عند أول تشغيل

من **الإعدادات ← الأذونات** داخل التطبيق:

| الصلاحية | الاستخدام | ملاحظة |
|---|---|---|
| إمكانية الوصول (Accessibility) | تنفيذ المهام على الشاشة | إجباري للمهام فقط، وليس للمحادثة |
| الظهور فوق التطبيقات | الفقاعة العائمة + الإيقاف | مفيد أثناء المهام الطويلة |
| البطارية غير مقيّدة | منع إنهاء المهمة | اختياري لكن مُوصى به |
| الميكروفون | الإدخال الصوتي | يُطلب عند أول استخدام للميكروفون |
| الملفات | تحميل النماذج المحلية | حسب نسخة أندرويد |

> لا تمنح إمكانية الوصول لتطبيق لا تثق به؛ الوكيل يقرأ محتوى الشاشة لتنفيذ أوامرك.

## 3) إعداد النموذج (المحادثة)

### نموذج سحابي
1. **الإعدادات ← النماذج**.
2. اختر المزوّد (OpenAI / Anthropic / DeepSeek / Google / Custom).
3. الصق **API Key**.
4. عدّل **Base URL** فقط إذا كنت تستخدم وسيطًا أو مزودًا متوافقًا (مثال: `https://openrouter.ai/api/v1`).
3. اضغط **اختبار** — ستظهر رسالة نجاح أو سبب الفشل (مفتاح خاطئ/رابط/شبكة/مهلة).
5. اختر النموذج ثم **حفظ**.

### نموذج محلي (بدون إنترنت)
1. **المهام/المحادثة** تعمل مع السحابة، والنموذج المحلي اختياري.
2. في صفحة النماذج، انزل لقسم النماذج المحلية، حمّل النموذج المناسب لذاكرة جهازك، ثم «استخدام».
3. أول تحميل قد يستغرق وقتًا ويحتاج مساحة تخزين.

## 4) المحادثة

- اكتب في المربع السفلي واضغط إرسال.
- الردود تُعرض **نصًا مكتوبًا** مع تنسيق Markdown (عريض/أكواد/روابط) وبث مباشر أثناء التوليد.
- التبديل بين **محلي/سحابي** من أعلى الشاشة.
- المحادثات تُحفظ محليًا ويمكن استرجاعها/حذفها/إعادة تسميتها من القائمة الجانبية.

## 5) المهام (التحكم بالهاتف)

1. من الشاشة الرئيسية اختر تبويب **مهمة** (عند استخدام النموذج المحلي) أو اكتب أمرًا تنفيذيًا في وضع السحابة.
2. مثال: «افتح واتساب وأرسل لفلان: سأتأخر».
3. يقرأ الوكيل الشاشة وينفّذ خطوات (ضغط/كتابة/تمرير) حتى الإنهاء أو الحد الأقصى للتكرارات.
4. تظهر شريط حالة المهمة وزر **إيقاف طارئ**.

### التأكيدات
قبل أي إجراء حسّاس تظهر نافذة تأكيد:
- إرسال رسالة أو ملف، إجراء مكالمة.
- دفع/تحويل مالي أو أي نص يحتوي كلمات دفع.
- حذف/مسح، تثبيت تطبيق، نشر محتوى.

**السماح** ينفّذ الإجراء، و**الرفض** يوقف المهمة كاملة. إذا كان التطبيق في الخلفية تُرفض الإجراءات تلقائيًا (حماية).

### التطبيقات المحظورة
- افتراضيًا: تطبيقات البنوك والمحافظ ومديري كلمات المرور والمصادقة.
- لتخصيص القائمة: **الإعدادات ← الأدوات ← تطبيقات محظورة** واكتب أنماطًا مفصولة بفواصل (مثل `bank, wallet, password`). القائمة المخصّصة **تستبدل** الافتراضية.
- إذا كان التطبيق الحالي محظورًا تُوقف المهمة فورًا برسالة واضحة.

### الإيقاف والمهلة
- **إيقاف طارئ**: شريط أحمر في المحادثة، زر في إشعار المهمة، والفقاعة العائمة.
- **مهلة المهمة**: من الإعدادات ← الأدوات (120/180/300/600 ثانية). عند بلوغها تُوقف المهمة وتظهر رسالة.

## 6) الإدخال الصوتي

1. اضغط زر الميكروفون بجانب مربع الكتابة.
2. اسمح بالميكروفون عند الطلب.
3. يظهر شريط تسجيل: نبض، مؤقت، النص الجزئي، وزر **إلغاء**.
4. اضغط الميكروفون مجددًا لإيقاف التسجيل مع إرسال النتيجة.
5. النص النهائي يُضاف إلى ما كتبته ويبقى **قابلًا للتعديل**.
6. لتفعيل الإرسال التلقائي: **الإعدادات ← الأدوات ← إرسال الإدخال الصوتي تلقائيًا** (افتراضيًا معطّل).

ملاحظات:
- اللغة المطلوبة **ar-SA**، وقد يعمل محليًا إذا كانت حزمة العربية مثبتة في خدمة التعرف بالجهاز، أو عبر الشبكة إن لم تكن.
- في الضجيج أو عند عدم وضوح الكلام تظهر رسالة عربية مناسبة.
- حد أقصى للتسجيل ~60 ثانية، ويُحتفظ بآخر نص جزئي عند انتهاء المهلة.

## 7) السجل والخصوصية

- **سجل الإجراءات** (الإعدادات ← الأدوات ← سجل الإجراءات): محلي فقط، يسجّل الأداة ونوع الخطورة والنتيجة، مع إخفاء المفاتيح وكلمات المرور والأرقام الشبيهة بالبطاقات. يمكن مسحه.
- مفاتيح API تُخزَّن مشفّرة على الجهاز.
- لا يوجد تحويل نص إلى كلام؛ الردود مكتوبة.
- المحادثات والبيانات محلية، وطلبات النموذج السحابي تذهب لمزوّدك المختار فقط.

## 8) إعدادات أخرى

- **اللغة**: عربية افتراضيًا، مع إمكانية التبديل للإنجليزية.
- **التعليمات العامة (Global prompt)**: تعليمات تُضاف لكل محادثة/مهمة، وتستطيع تجاوز سياسة الرد العربية إن أردت.
- **الأتمتة الخارجية**: لتشغيل مهام من Tasker/MacroDroid؛ معطّلة افتراضيًا، ولا تُفعّلها إلا إذا كنت تتحكم بالتطبيقات التي ستناديها.
- **خادم الإعدادات المحلي**: يعمل على `127.0.0.1` فقط، ويتطلب رمزًا مضمّنًا في الصفحة التي يقدّمها.

## 9) استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| «لم يتم اختيار نموذج» | الإعدادات ← النماذج ← أدخل المفتاح واختر نموذجًا ثم حفظ |
| فشل اختبار الاتصال (401) | تحقق من صحة المفتاح واختيار المزوّد الصحيح |
| فشل 404/النموذج غير موجود | صحّح اسم النموذج أو Base URL |
| مهلة الشبكة | تحقق من الإنترنت أو جرّب لاحقًا؛ قد يمنع الوكيل/الشبكة الوصول |
| المهمة تتوقف عند تطبيق | إذا كان مصرفيًا/كلمات مرور فهذا مقصود؛ عدّل القائمة إن كان حظرًا خاطئًا |
| المهمة تتوقف فورًا برسالة رفض | وافقت؟ الرفض يوقف المهمة؛ أعد المحاولة واختر «السماح» |
| لا يعمل الميكروفون | امنح إذن الميكروفون، وتأكد من تثبيت حزمة اللغة العربية في خدمة التعرف |
| ترقية APK تفشل | أزل النسخة القديمة ثم ثبّت (`adb uninstall io.agents.pokeclaw`) |
| النموذج المحلي لا يُحمَّل | مساحة/ذاكرة غير كافية أو تحميل ناقص؛ أعد التحميل |

## 10) ما لم يُتحقق على جهاز حقيقي

هذه النسخة بُنيت واجتازت 127 اختبار وحدة، لكن لم يُنفَّذ اختبار شامل على جهاز/محاكي في هذه المرحلة. لذلك **لم نتحقق عمليًا** من:
- نوافذ التأكيد وحظر التطبيقات والإيقاف الطارئ والمهلة.
- سلوك خدمة إمكانية الوصول على أجهزة مختلفة.
- دقة التعرف الصوتي العربي وحزمة ar-SA على جهاز فعلي.
- تنفيذ المهام الحقيقية على تطبيقات مثل واتساب/البنوك.
- أداء النماذج المحلية على أجهزة منخفضة الذاكرة.

تجد قوائم الاختبار الجاهزة للتنفيذ في `QA_CHECKLIST.md` (الأقسام FA وVA وSA).
